## MemReduct RS v0.3.0

下载 **MemReduct-RS-0.3.0-x64-Setup.exe** 安装。Windows 10/11 x64；启动自动请求管理员权限。

- 一体化原生界面：取消系统标题栏与边框，自绘最小化/关闭、可拖动标题区；主界面与设置页在同一窗口切换；策略使用分段按钮。
- 数字托盘：直接显示内存占用百分比的数字，如 9、85、100；蓝色常规、达到配置阈值变为琥珀色、94% 及以上红色；0 显示为 0，不使用静态应用图标假装实时数字。
- 8 个模式：智能选策、轻量缓存、后台回收、系统缓存、待机回收、均衡回收、压力回收、深度清理。
- 智能选策根据可用内存、物理占用、待机缓存和系统缓存选择具体操作，显示选择原因；内存充足跳过清理，严重压力下选择受筛选的工作集与缓存回收。不会自动选择全局工作集清空或修改页刷新。
- 新安装默认智能选策；升级保留原有策略。点击「智能选策」会同时将手动与自动策略切为智能，但不会擅自开启自动优化。
- 更换透明、单色线条芯片图标；桌面、开始菜单、任务栏、安装器同步更新，托盘独立使用数字图标。
- Windows CI 检查自定义拖动区、内嵌设置页、非法设置拒绝、保存后恢复总览、最小化/恢复和安装卸载；输出界面与 16/24/32px 数字托盘预览。

自动触发保留持续判定、冷却、回差及默认全屏暂停。数字表示物理内存占用百分比，% 符号放在悬停提示中以保证小图标可读性。

工作集/缓存回收不等于解除应用分配或修复泄漏，不能保证提升游戏帧率。实际负载收益、Windows 10/11 桌面与不同 DPI 的长期体验仍需用户机器验证。程序未签名。
