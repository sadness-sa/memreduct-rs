## MemReduct RS v0.4.0

下载 **MemReduct-RS-0.4.0-x64-Setup.exe**。Windows 10/11 x64。

- 「优化设置 → 托盘外观」：背景色可随占用自动变化，常规/警告/危险背景与数字文字色分别配置；支持十六进制输入、颜色预览和系统选色器。变色阈值独立于清理阈值，也可关闭动态变色，固定使用常规背景。
- 「优化设置 → 自动清理」：选择按内存占用、按固定时间间隔，或任一条件触发；可设置自动开关、间隔、占用阈值、持续时间、冷却和回落幅度。自动执行仍受全屏暂停与冷却约束，智能策略在内存充足时可跳过回收。
- 「进程保护」独立页面保留最小工作集与进程排除列表；切换页签不丢失未保存的输入，点击保存后生效。
- 安装器显式读取已有安装的 64 位注册表路径，兼容旧的 32 位记录；更新复用原目录，直接进入安装，不再重复选择目录。
- 更新前尝试正常退出旧程序；正在清理或有对话框阻塞时提示等待，不强行结束。首次安装仍可选择目录；保留用户配置和额外文件。
- Windows CI 覆盖触发方式和托盘配置保存、非法颜色拒绝、安装/可见直接更新/卸载，以及自定义安装路径与用户文件保留。

升级保留旧配置及触发语义：旧版设置了非零定时间隔时仍按“占用或时间”判断，未开启自动优化的用户不会被自动开启。托盘新增字段使用原有三档默认配色。

工作集和缓存回收不等于解除应用分配；实际负载收益仍待用户机器验证。程序未签名。
