## MemReduct RS v0.2.0

Windows 10/11 x64 安装版。下载 **MemReduct-RS-0.2.0-x64-Setup.exe**，运行安装后从开始菜单或桌面启动。

- 现代浅色卡片界面、实时内存曲线、应用自身工作集显示、可视化设置。
- GUI 启动自动请求 UAC 管理员权限；CLI 状态查询保留普通权限。
- 均衡回收增加空闲后台进程工作集处理，跳过前台进程树、系统关键进程、其他会话、CPU 繁忙进程和用户排除项。
- 单独显示系统可用内存、待机缓存、提交量、进程工作集变化与逐项错误；完全失败时不再显示虚假的 +0.0 MiB 成功感。
- 自动模式可选择轻量缓存或均衡回收，默认暂停全屏游戏/演示期间的自动清理，保留持续判定、冷却与回差。
- 真正的 NSIS 安装程序：开始菜单、桌面快捷方式、程序列表卸载和版本信息。保留用户设置，安装前应先从托盘退出旧版。
- 成品由 Windows MSVC CI 从本版本源码构建；发布前校验清单、CLI 查询、GUI 启动退出、安装与卸载。

**升级提示：**保留旧配置；如旧版选择了保守策略，请在主界面改为「均衡回收」。自动清理仍默认关闭，自动模式默认轻量缓存。

待机页原本已属于可用内存；工作集回收也不会解除应用的内存分配或修复泄漏，后续访问可能触发缺页重载。不能保证提高游戏帧率。需要进一步进行真实 Windows 10/11 桌面、UAC 交互和负载性能验收。程序未签名。
