# v0.2.0 验证与验收

## 自动检查

以 [GitHub Actions](https://github.com/sadness-sa/memreduct-rs/actions) 对当前提交的运行记录为准，不把配置文件本身当作通过证据。

- Linux/Windows：rustfmt、Clippy（warnings as errors）、纯逻辑测试。
- 测试覆盖自动策略、配置错误保留、旧配置兼容、禁止自动强力清理、排除列表校验、前台进程树/同名进程保护、循环/缺失父进程、参数错误、部分/全部失败与负内存差值。
- Windows MSVC Release：构建 GUI/CLI，提取 PE 清单，验证 GUI requireAdministrator / CLI asInvoker。
- 只读 CLI：检查物理总量和可用内存计数；未在 CI 上清空系统工作集或缓存。
- GUI 冒烟：启动窗口、捕获预览、发送正常退出消息；不等同于人工视觉及全部控件验收。
- NSIS 安装器：静默安装到临时目录、检查 EXE/卸载器/文档、运行已安装 CLI status，再静默卸载并确认主程序移除。
- Release：只从检查通过的相同提交构建安装程序，校验 SHA-256 后发布，保留 v0.1.0 历史版本。

## 需要在用户真实 Windows 机器验证

| 场景 | 预期 |
| --- | --- |
| 安装/升级/卸载 | 快捷方式和程序列表入口正确；旧程序在运行时提示先退出；用户设置保留 |
| 从桌面启动、同意 UAC | GUI 自动提升；不再因普通令牌缺少 SeProfileSingleProcessPrivilege 直接失败 |
| 取消 UAC / 使用无管理员凭据账户 | Windows 阻止启动；不能宣称已提升或清理 |
| 组织策略移除权限 | 即使已提升也清楚报告令牌缺少权限，不报告成功 |
| 中文与 100%/125%/150%/200% 缩放 | 卡片、曲线、设置窗口和按钮可见，文字不截断；窗口按屏幕高度限制初始尺寸 |
| 均衡回收 | 前台应用/同名进程/进程树与用户排除项跳过；展示后台成功、跳过、不可访问和失败统计 |
| 工作集统计 | 前后系统可用、待机缓存和提交量有明确口径；单个进程 WS 变化不宣称为物理内存精确释放量 |
| 自动清理 | 高占用持续达到阈值才触发，手动/自动都遵守冷却，默认全屏游戏或演示时暂停 |
| 强力模式 | 每次确认，明确不使用后台进程排除；取消不执行 |
| 托盘与快捷键 | 关闭隐藏、恢复、退出、Explorer 重启重建；快捷键冲突可见 |
| 设置保存/取消 | 非法参数显示错误；取消不改变配置；写失败保持原配置 |
| 空闲常驻 | GUI 可见与托盘隐藏分别测 Working Set、Private Bytes、CPU 时间和 GDI/USER 句柄，持续 30 分钟检查无增长 |

## 性能对照

固定机器、Windows 构建和负载，比较不清理、v0.1.0、v0.2.0 各模式。清理前后连续记录可用内存、提交量、硬缺页、磁盘读取与游戏帧时间，至少 5 轮交替顺序。不能用“工作集变小”代替性能结论；如缺页或卡顿增多应减少清理频率或排除目标进程。

本项目未通过虚构数字宣称常驻占用降低百分比；实际效果需要用户机器数据。完整桌面 UAC 交互、真实清理效果与性能对比仍待实测。
