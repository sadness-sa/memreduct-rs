# v0.3 开发需求与后续计划

## 用户目标

参考 Mem Reduct，用 Rust 重构 Windows 常驻内存监控和清理工具。以低资源常驻、清理行为可解释、减少高占用时重复清理为目标。

## 功能要求

| 编号 | 要求 | 实现位置 |
| --- | --- | --- |
| F01 | 中文桌面界面，现代卡片界面、曲线，显示物理内存、待机缓存和应用自身工作集 | `ui.rs`、`platform/windows.rs` |
| F02 | 三档手动策略，强力模式确认 | `model.rs`、`ui.rs`、`cli.rs` |
| F03 | 高占用持续触发、回差、冷却、可选定时清理 | `policy.rs` |
| F04 | 自动策略可选轻量缓存/均衡回收，默认关闭，全屏暂停 | `ui.rs`、`config.rs` |
| F05 | 系统托盘、关闭隐藏、Explorer 重启重建 | `ui.rs` |
| F06 | Ctrl+Alt+M 全局快捷键，可禁用 | `ui.rs` |
| F07 | GUI 自动请求管理员权限；CLI status 普通权限；权限错误可见 | `ui.rs`、`platform/windows.rs` |
| F08 | TOML 配置、严格验证、便携存储、原子替换 | `config.rs` |
| F09 | JSON 状态/结果、明确 CLI 退出码 | `cli.rs` |
| F10 | 保留逐项结果、带符号内存变化、轮转日志 | `model.rs`、`config.rs` |
| F11 | 均衡模式筛选空闲后台进程，排除前台进程树与用户列表 | `selection.rs`、`platform/windows.rs` |
| F12 | 可视化设置、现代卡片界面、管理员安装器与卸载 | `settings.rs`、`ui.rs`、`installer/` |
| F13 | 一体化无系统标题栏界面与内嵌设置，数字托盘 | `ui.rs`、`settings.rs`、`tray.rs` |
| F14 | 智能选策与 7 种手动策略，展示选策理由 | `strategy.rs`、`model.rs` |

以上“实现”指源码路径已具备，运行验收状态以 `VALIDATION.md` 为准。

## 非功能要求

- Windows 10/11 x64；无 WebView、后台网络或遥测依赖。
- 清理不阻塞 UI；同一 Windows 会话内清理串行执行。
- 清理失败不能呈现为成功，错误配置不能静默覆盖为默认值。
- 不以单次可用内存变化宣称程序或系统变快。
- 携带 Cargo.lock、GPLv3 许可证、来源说明、构建说明和测试流程。
- CPU、Private Bytes、句柄增长和游戏帧时间的可接受阈值待实机基线测量后确定，不凭推测填写。

## 后续优先顺序

1. **实机兼容验证**：先在 Windows 10/11 上验证权限、托盘、UAC、DPI 和清理结果，修复后才发布稳定版。
2. **资源与体验优化**：取得原版对照数据后调整采样频率、刷新粒度和默认触发阈值；补数字托盘图标、跨屏 DPI 和快捷键自定义。
3. **系统集成**：任务计划程序开机启动、代码签名；v0.2 已加入 NSIS 安装/卸载；明确处理管理员任务和普通用户会话的关系。
4. **扩展清理项**：先评估注册表缓存、物理页合并的系统版本兼容和实际收益，再加入独立选项；不默认加入自动清理。
5. **更多平台架构**：ARM64 构建、CI 和实机验证。不将 Linux/macOS 的缓存接口视为 Windows 实现的直接移植。
